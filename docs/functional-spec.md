# 機能仕様

## 1. 画面構成

左ペインにファイルツリー、右ペインにエディタを置く 2 ペイン構成とする。

```text
┌──────────────────────────────────────────────────────────────┐
│ メニュー / ツールバー                     [AI ▼]            │
├──────────────────┬───────────────────────────────────────────┤
│ 左ペイン         │ 右ペイン                                  │
│ (ファイルツリー) │ ┌ タブ: [設計メモ.md] [todo.md ●] ──────┐ │
│                  │ │ [編集] [プレビュー] [分割]             │ │
│ 📁 C:\Notes      │ ├────────────────────────────────────────┤ │
│ ├ 📁 inbox       │ │ # 設計メモ                             │ │
│ │ └ 📄 memo.md   │ │                                        │ │
│ ├ 📁 projects    │ │ - [ ] 左ペインの実装                   │ │
│ │ ├ 📄 設計メモ  │ │ - [x] 仕様の整理                       │ │
│ │ └ 📄 todo.md   │ │                                        │ │
│ └ 📄 README.md   │ ├────────────────────────────────────────┤ │
│                  │ │ ターミナル（表示 / 非表示）            │ │
│ [🔍 検索]        │ │ PS C:\Notes> claude                    │ │
│                  │ └────────────────────────────────────────┘ │
├──────────────────┴───────────────────────────────────────────┤
│ ステータスバー: 文字数 / 行:列 / 保存状態 / ブランチ           │
└──────────────────────────────────────────────────────────────┘
```

- **左ペイン**: ルートディレクトリ以下のフォルダと Markdown ファイルをツリーで表示する（§2）。上部の切り替えで「ファイル」「検索」「アウトライン」「Git」を表示する。`Ctrl+Shift+E` で表示を切り替える。「Git」はルートディレクトリが Git で管理されているときの変更・コミット・ブランチ・履歴の操作（[git.md](git.md)）で、`Ctrl+Shift+G` で表示する。
- **右ペイン**: 開いたファイルと Git の差分（[git.md](git.md) §3.2）をタブで表示する。ファイルのタブでは表示モードを切り替える。
  - 編集: エディタのみ（既定）
  - プレビュー: 描画結果のみ
  - 分割: 右ペインの中を左右に分け、エディタとプレビューを並べる
  - `Ctrl+Shift+V` で順に切り替える。
- **ターミナル**: 右ペインの下部に表示する。`` Ctrl+` `` で表示を切り替える（[terminal-ai.md](terminal-ai.md)）。
- 左右ペインの境界、エディタとターミナルの境界はドラッグで大きさを変えられる。
- ウィンドウの配置、ペインの大きさ、開いていたタブは終了時に保存し、次回起動時に復元する。
- 文字の大きさは `Ctrl` + マウスホイールで 1px ずつ変えられる（8〜40px）。カーソルの下にあるエディタ・プレビュー・ターミナルのそれぞれが対象で、変えた値は設定に保存する。ページ全体の拡大はしない。

## 2. ディレクトリとファイル

### 2.1 基本の考え方

- データベースは使わない。**ユーザーが指定したディレクトリ（ルートディレクトリ）の中を再帰的に探し、見つかった Markdown ファイルを表示・編集する**。ファイルシステムそのものが唯一のデータになる。
- ルートディレクトリの中にアプリ用のファイルやフォルダを作らない。アプリの設定と状態は `%APPDATA%` / `%LOCALAPPDATA%` に保存する（[architecture.md](architecture.md)）。
- ファイル一覧はメモリ上だけに持ち、保存しない。起動時やディレクトリを開いたときに毎回探し直す。

### 2.2 ルートディレクトリの指定

- 「フォルダを開く」（`Ctrl+O`）で任意のディレクトリを指定する。エクスプローラーからフォルダをウィンドウにドラッグ＆ドロップしても開ける。
- コマンドラインからも指定できる: `mark-shell.exe C:\Notes`
- エクスプローラーの右クリックメニューに「mark-shell で開く」を出す（フォルダ、フォルダの空いている所、ファイル）。既定で有効で、起動のたびに実行ファイルの場所と言語を登録し直す。設定画面で外せる。`HKCU` に登録するので管理者権限は不要。インストーラー版はアンインストールで消える。Windows 11 では「その他のオプションを確認」の中に出る。
- ファイルを指定して開いたときは、そのファイルを含む最近開いたフォルダ（なければファイルのあるフォルダ）を開き、ファイルを表示する。
- 最近開いたディレクトリを記録し、ようこそ画面とメニューから選べるようにする。`Ctrl+R`（またはツールバーのフォルダ名のメニュー、コマンドパレット）で、最近開いたディレクトリを名前で絞り込んで選べる。Shift+Enter か右クリックで新しいウィンドウで開ける（ようこそ画面の一覧も右クリックで同じ）。
- 起動時にコマンドラインでの指定がなければ、前回開いていたディレクトリを開く。そのディレクトリがなくなっていれば、ようこそ画面を出す。
- ウィンドウ 1 つにつきルートディレクトリは 1 つ。複数を同時に扱う場合は新しいウィンドウで開く。

### 2.3 再帰的な探索

| 項目 | 仕様 |
| --- | --- |
| 対象ファイル | 拡張子にかかわらずすべてのファイルとフォルダ。隠しファイル、`.gitignore` の対象、`.git` や `node_modules` も除外しない。拡張子が `.md` / `.markdown` / `.mdx` のもの（設定で変えられる）を Markdown として扱う |
| Markdown 以外のファイル | テキストなら編集モードだけで開く（プレビュー・アウトライン・Markdown の書式のショートカット・HTML や画像の貼り付けの変換はない）。拡張子（なければ先頭の行の `#!/usr/bin/env python` や `<?php` など）で分かる言語（TypeScript、PHP、JSON、YAML など）は色付けする。自動で選んだ言語が違うときは、ステータスバーの言語名か「言語モードの変更」から手動で選べる（ファイルごとに覚える）。50MB を超えるファイルと、先頭に NUL を含むバイナリのファイル（画像、Office、PDF など）はエディタで開かず、Windows の既定のアプリで開くか尋ねる |
| 表示するフォルダ | 空のフォルダも含めてすべて |
| シンボリックリンク / ジャンクション | 既定ではたどらない（無限ループを防ぐ）。設定でたどる場合も、同じ実体を 2 度たどらない |
| 深さ | 制限なし。ただしファイル数が 50,000 を超えたら探索を止めて通知し、より狭いフォルダを開くよう案内する |
| 並び順 | フォルダが先、その後ファイル。名前の自然順（`2.md` < `10.md`）。設定で更新日時順にもできる |
| 表示名 | ファイル名（拡張子を含む）。設定でフロントマターの `title` または最初の見出しを表示することもできる |

- 探索はバックグラウンドで行い、見つかった順にツリーへ追加する。探索中も UI は操作できる。
- フォルダの開閉状態は記録し、次回開いたときに復元する。

### 2.4 ファイル操作（左ペイン）

| 操作 | 仕様 |
| --- | --- |
| 開く | クリックで仮タブ（次のファイルを開くと置き換わる）、ダブルクリックまたは編集開始で固定タブとして開く |
| 新規ファイル | 右クリック →「新しいファイル」、または `Ctrl+N`（選択中のフォルダに作る）。ファイル名を入力する（拡張子は省略時 `.md`） |
| 新規フォルダ | 右クリック →「新しいフォルダ」 |
| 名前変更 | `F2`。そのファイルへの相対リンクを持つ他のファイルを探し、リンクを書き換えるか確認する |
| 移動 | ドラッグ＆ドロップ。リンクの書き換えは名前変更と同じ |
| 外からのコピー | エクスプローラーなどからファイル・フォルダをツリーにドロップすると、落としたフォルダ（ファイルの行ならそのフォルダ、空いている所ならルート）にコピーする。ドラッグ中はコピー先を強調表示する。同じ名前があれば `名前 (2).md` のように番号を付ける（上書きしない）。ツリー以外に落としたときはこれまでどおり（画像はリンクを挿入、ファイルは開く、フォルダはルートとして開く） |
| 削除 | `Delete`。Windows のごみ箱へ移す（アプリ独自のゴミ箱は持たない） |
| 複製 | 右クリック →「複製」 |
| その他 | 「エクスプローラーで表示」「パスをコピー」「相対パスをコピー」「ここでターミナルを開く」 |
| Git | Git で管理されているときは「変更を表示」「このファイルの履歴」「変更を破棄」「ステージ」「.gitignore に追加」。ツリーの名前には変更の状態を色と記号で示す（[git.md](git.md) §3.3） |

### 2.5 メタデータ

- 先頭の YAML フロントマターがあれば解釈する（`title`, `tags` など）。なくても動く。
- フロントマターはプレビューでは折りたたんだ表として表示する。

## 3. エディタ

- エンジン: CodeMirror 6（[architecture.md](architecture.md)）。
- Markdown のシンタックスハイライト。フェンスコードブロック内は言語ごとにハイライトする。
- 入力補助
  - リストの継続（Enter で次の項目を作る。空の項目で Enter を押すとリストを抜ける）
  - `Tab` / `Shift+Tab` でリストの字下げを変える
  - 括弧・引用符・`**` などを自動で閉じる
  - `[[` または `](` でルートディレクトリ内のファイル名を補完する
  - 表の整形（`Alt+Shift+F` で列幅をそろえる）
- 書式ショートカット: `Ctrl+B` 太字、`Ctrl+I` 斜体、`Ctrl+K` リンク、`Ctrl+Shift+C` コードブロック、`Ctrl+Enter` タスクのチェック切り替え。
- 保存: 自動保存（入力停止後 1 秒、フォーカスを外したとき）。`Ctrl+S` で即時保存。未保存のタブには ● を表示する。
- IME: 日本語変換中は補完と自動整形を止める。変換中の文字列がプレビューに一時的に反映されないこと。
- 検索・置換（正規表現対応）、複数カーソル、行の折り返し切り替え、行番号の表示切り替え。
- Git で管理されているファイルでは、行番号の横に HEAD からの変更を色の帯で示す（[git.md](git.md) §3.3）。
- 貼り付け
  - 画像: 編集中のファイルと同じフォルダの `assets/` に `<ファイル名>-<連番>.png` として保存し、`![](assets/...)` を挿入する（保存先は設定で変更可）。
  - HTML（Web ページからのコピー）: Markdown に変換して貼り付ける。「プレーンテキストで貼り付け」（`Ctrl+Alt+V`）も用意する。

## 4. プレビュー

### 4.1 対応する記法

| 分類 | 内容 |
| --- | --- |
| 基本 | CommonMark 0.31 |
| GFM | 表、タスクリスト、取り消し線、自動リンク、脚注 |
| コード | フェンスコードブロックのハイライト（Shiki、テーマはエディタと連動） |
| 数式 | KaTeX（インライン `$...$`、ブロック `$$...$$`） |
| 図 | Mermaid（フローチャート、シーケンス図、ガントチャートなど） |
| 注記 | GitHub 形式のアラート（`> [!NOTE]`, `> [!WARNING]` など） |
| ファイル間リンク | 相対パスのリンク `[表示名](../other.md)`、`[[ファイル名]]`、`[[ファイル名#見出し]]`、`[[ファイル名\|表示名]]` |
| HTML | 安全なタグのみ許可（`<details>`, `<kbd>`, `<sub>`, `<sup>`, `<br>` など）。`<script>` やイベント属性は除去する |

- `[[ファイル名]]` は、メモリ上のファイル一覧から同じ名前のファイルを探して解決する。同名のファイルが複数ある場合は、リンク元に近いもの（同じフォルダ → 親フォルダ → それ以外）を選ぶ。

### 4.2 振る舞い

- 分割表示ではエディタとスクロール位置を同期する（見出し・段落単位で対応付ける）。
- プレビューのタスクリストをクリックすると元の Markdown の `[ ]` / `[x]` を書き換える。
- ファイル間リンクのクリックでそのファイルを開き、左ペインのツリーでも選択状態にする。外部リンクは既定のブラウザで開く（確認ダイアログあり）。
- 印刷と、PDF / HTML へのエクスポート。エクスポート結果はプレビューと同じ見た目にする。

### 4.3 セキュリティ

- 描画結果は DOMPurify でサニタイズしてから表示する。
- プレビューからはネットワークアクセスをしない（CSP で外部リソースの読み込みを禁止）。外部画像 URL は既定ではプレースホルダーを表示し、クリックしたときだけ読み込む（設定で常に読み込むこともできる）。
- ルートディレクトリの外にあるローカルファイルへの画像参照は表示しない。

## 5. 検索・ナビゲーション

検索用のインデックスは作らず、その都度ファイルを走査する。

- **クイックオープン**（`Ctrl+P`）: メモリ上のファイル一覧からファイル名・パスをあいまい検索する。
- **全文検索**（`Ctrl+Shift+F`）: 左ペインを検索表示に切り替え、ルートディレクトリ以下の Markdown ファイルを直接走査する。
  - 見つかった順に結果を表示する（全件そろうのを待たない）。検索語を変えたら前の走査を中断する。
  - 大文字小文字の区別、単語単位、正規表現、フォルダでの絞り込みを指定できる。
  - 結果のクリックで該当行を開く。検索結果に対する一括置換もできる（実行前に件数を確認）。
- **アウトライン**: 左ペインのアウトライン表示で、開いているファイルの見出し一覧を表示する。
- **Git**（`Ctrl+Shift+G`）: 左ペインの Git 表示で、変更・コミット・ブランチ・履歴を扱う（[git.md](git.md)）。
- **このファイルへのリンクを探す**: 右クリックメニューから、開いているファイルへのリンクを全文検索で探す。
- **コマンドパレット**（`Ctrl+Shift+P`）: 全コマンドを検索・実行する。

## 6. 外部での変更への対応

- ルートディレクトリ以下のファイル変更を監視する（他のエディタ、クラウド同期ソフト、Git、AI ツールによる変更）。
- ファイルの追加・削除・名前変更は左ペインのツリーに即座に反映する。
- 作業ツリーや `.git` の中が変わったら、Git タブ・ツリーの状態の色・エディタの変更の帯を更新する（[git.md](git.md) §5）。
- 開いているファイルが外部で変わったとき
  - 未保存の変更がなければ、黙って読み込み直す（カーソル位置はできるだけ保つ）。
  - 未保存の変更があれば、差分を表示して「自分の変更を残す / 外部の変更を取り込む / 両方を残す」を選ばせる。
- 開いているファイルが外部で削除されたときは、タブを残したまま「削除されました」と表示し、保存すれば作り直せるようにする。
