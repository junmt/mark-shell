# 要求事項と要件

## 1. 要求事項（原文）

| ID | 要求 |
| --- | --- |
| R1 | Windows アプリ |
| R2 | マークダウンでメモを書く |
| R3 | マークダウンをちゃんと表示できる |
| R4 | ネットワークに繋がなくても使える |
| R5 | パソコン間で同期できる（**一旦要件から外す。実現方法は別途検討**） |
| R6 | シェルを開いて Claude や Antigravity などインストールされている AI が使える |
| R7 | DB は使わず、ディレクトリを指定するとその中のマークダウンファイルを再帰的に探して表示・編集できる |
| R8 | 左ペインにファイル（ディレクトリ）、右ペインにエディタを置く |
| R9 | Git で管理されているフォルダでは、Git の操作やコミット、リモートリポジトリのブランチやコミットの表示ができる。変更の差分も見られる |

## 2. 要件への展開

### R1: Windows アプリ

- 対象 OS: Windows 10（22H2 以降）/ Windows 11、x64 と ARM64。
- インストーラー（MSI / NSIS）と、インストール不要のポータブル版（zip）を配布する。
- 管理者権限なしでユーザー単位にインストールできる。
- 配色: Windows の設定に合わせたライト / ダーク（既定）、プリセット（ライト、ダーク、セピア、Solarized ライト・ダーク、Nord、ハイコントラスト）、プリセットを元に背景・文字・強調色などを変えるカスタム。ホバーや選択などの中間の色は基本の色から計算する。
- フォント: 画面全体、エディタ、プレビュー、ターミナルのそれぞれで指定できる。設定画面で見本を表示する。
- 表示言語: 日本語・英語・中国語（簡体字）。既定では PC（Windows の表示言語）に合わせ、それ以外の言語のときは英語にする。設定画面で切り替えられ、すぐに反映する。エラーメッセージ、WSL のエージェント、Claude Code に伝える文脈、AI ツールの既定のメニュー、エクスプローラーの右クリックメニューも選んだ言語にする。
- 高 DPI と、複数モニターで異なる拡大率の環境に対応する。

### R2: マークダウンでメモを書く

- 1 ファイル 1 メモの `.md` を編集する。既存ファイルの文字コード・改行コードは保ち、新規作成は UTF-8（BOM なし）、LF とする。
- Markdown のシンタックスハイライト、補完（括弧・リスト継続）、ショートカットを持つエディタ。
- 自動保存（入力停止後 1 秒、およびフォーカスを外したとき）。
- 画像の貼り付け・ドラッグ＆ドロップで編集中のファイルと同じ場所の `assets/` に保存し、相対リンクを挿入する。
- ファイル間リンク（通常の相対リンクと `[[ファイル名]]` 形式の両方）。
- 詳細は [functional-spec.md](functional-spec.md) を参照。

### R3: マークダウンをちゃんと表示できる

「ちゃんと」を以下の水準と定義する。

- CommonMark と GitHub Flavored Markdown（表、タスクリスト、取り消し線、自動リンク、脚注）に準拠する。
- コードブロックのシンタックスハイライト（主要 50 言語以上）。
- 数式（KaTeX: `$...$`, `$$...$$`）。
- 図（Mermaid: ```` ```mermaid ````）。
- 日本語の表示品質: 和文フォントの指定、禁則処理、全角と半角の混在で崩れないこと。
- 相対パスの画像・ファイル間リンクが正しく解決されること。
- GitHub での表示と大きく食い違わないこと（受け入れテストで確認する）。

### R4: ネットワークに繋がなくても使える

- アプリ本体はネットワークアクセスなしで全機能が動く。フォント、KaTeX、Mermaid、ハイライト定義などはすべてアプリに同梱し、CDN を使わない。
- 起動時のアカウントログインやライセンス認証は求めない。
- 外部 AI ツール自体が通信を必要とする場合、それはツール側の制約であり、アプリはオフライン中でもシェルを起動できる。

### R5: パソコン間で同期できる

- 初期の要件からは外す。実現方法は別途検討する。
- 当面は、ルートディレクトリを OneDrive などの同期フォルダや Git リポジトリに置く運用で代替できる。アプリは外部でのファイル変更を検出して反映する（[functional-spec.md](functional-spec.md) §6）ので、この運用と矛盾しない。

### R6: シェルから AI を使う

- アプリ内にターミナルパネルを持ち、PowerShell / コマンドプロンプト / Git Bash / WSL を開ける。
- カレントディレクトリはルートディレクトリ（または開いているノートのフォルダ）にする。
- PC にインストールされている AI ツールを自動検出し、ワンクリックで起動できる。
  - 例: Claude Code（`claude`）、Antigravity、Gemini CLI（`gemini`）、Codex CLI（`codex`）
- AI ツールがファイルを書き換えたら、ファイルツリー・エディタ・プレビューに即座に反映する。
- 詳細は [terminal-ai.md](terminal-ai.md) を参照。

### R7: DB を使わずディレクトリを再帰的に扱う

- 任意のディレクトリ（ルートディレクトリ）を指定して開く。フォルダを開く操作、ドラッグ＆ドロップ、コマンドライン引数、エクスプローラーの右クリックメニューから開ける。
- ルートディレクトリ以下を再帰的に探し、Markdown ファイル（`.md` など）とそれを含むフォルダを一覧する。
- データベース・検索インデックスは使わない。ファイル一覧はメモリ上にのみ持ち、全文検索はその都度ファイルを走査する。
- ルートディレクトリの中にアプリ用のファイル・フォルダを作らない。設定は `%APPDATA%` などに置く。
- 隠しファイル、`.gitignore` の対象、`.git` や `node_modules` も含め、すべてのファイルとフォルダを表示する（除外はしない）。
- 詳細は [functional-spec.md](functional-spec.md) §2 を参照。

### R8: 2 ペイン構成

- 左ペインにディレクトリとファイルのツリー、右ペインにエディタを置く。
- 右ペインはタブで複数のファイルを開き、編集 / プレビュー / 分割（エディタとプレビューを並べる）を切り替える。
- ターミナルは右ペインの下部に表示・非表示を切り替えて表示する。
- 詳細は [functional-spec.md](functional-spec.md) §1 を参照。

### R9: Git 連携

- 左ペインの「アウトライン」の隣に「Git」タブを置き、そこから操作する。
- PC にインストールされている `git` を使う。ユーザーの設定・認証・フック・署名がそのまま効く。`git` がなくても他の機能は使える。
- 変更の一覧、ステージ（ファイル・ハンク・行ごと）、変更の破棄、コミット（修正コミットを含む）。
- 変更の差分を右ペインのタブで表示する（左右 / 行内、単語単位の強調、Markdown はプレビューでの比較）。ファイルツリーとエディタにも変更の印を出す。
- ブランチ（ローカル・リモート）とタグの一覧、切り替え、作成、削除。
- リモートリポジトリの表示: リモートごとのブランチ、取り込んでいない / プッシュしていないコミットの数、リモートのブランチの履歴と差分、現在のブランチとの比較（最後にフェッチした時点の内容）。
- マージ（ローカル・リモートのブランチ、タグ、コミットから。早送り / マージコミット / スカッシュ）とチェリーピック（複数のコミット、リモートのブランチのコミットも可）。
- コミットの履歴（ブランチのグラフ、リモート追跡ブランチの位置）、コミットごとの変更と差分、ファイルの履歴。
- フェッチ（すべて / リモート 1 つ / ブランチ 1 つ）・プル・プッシュ。通信はユーザーの操作でだけ行う（自動フェッチは既定で無効）。
- スタッシュ、マージの競合の解決。
- WSL のフォルダでは WSL の中の `git` を使う。
- 詳細は [git.md](git.md) を参照。

## 3. 非機能要件

| 項目 | 目標 |
| --- | --- |
| 起動時間 | ファイル 1,000 件のディレクトリで、ツリー表示まで 2 秒以内（コールドスタート） |
| ディレクトリ探索 | ファイル 10,000 件で探索完了まで 1 秒以内（ローカル SSD） |
| プレビュー更新 | 入力から 100ms 以内（1 万字のファイル） |
| 全文検索 | ファイル 10,000 件で最初の結果まで 200ms、全件の走査完了まで 1 秒以内（インデックスなし） |
| Git の状態表示 | 追跡ファイル 10,000 件のリポジトリで、ファイルの変更から Git タブの更新まで 1 秒以内 |
| メモリ使用量 | アイドル時 200MB 以下（ターミナル 1 つを含む） |
| 配布サイズ | インストーラー 30MB 以下 |
| データ保護 | 編集中にクラッシュしても失われる入力は最大 1 秒分 |
| プライバシー | テレメトリは既定で無効。アプリ自身は更新確認以外に通信しない |

ネットワークドライブやクラウド同期フォルダ（オンデマンドのファイル）上のディレクトリでは、探索と検索の目標値は適用しない。

## 4. 対象外（初期バージョン）

- パソコン間の同期（R5。別途検討）
- macOS / Linux / モバイル版（構成上は移植可能にしておく）
- 複数人でのリアルタイム共同編集
- データベースや検索インデックスを使う機能（タグ一覧、バックリンク一覧の常時表示など）
- アプリ内への AI モデル・API クライアントの組み込み
- Git のクローン、リベース、ホスティングサービス（GitHub など）との連携（[git.md](git.md) §7）
