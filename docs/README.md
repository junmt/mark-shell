# mark-shell 仕様書

mark-shell は Windows 向けのデスクトップアプリです。指定したディレクトリの中の Markdown ファイルを左ペインのツリーで一覧し、右ペインで編集・表示します。同じ画面のシェルから AI（Claude Code、Antigravity など）を呼び出せます。

## 基本方針

1. **データベースを使わない**  
   指定したディレクトリを再帰的に探し、見つかった `.md` ファイルをそのまま表示・編集する。ファイル一覧や検索はその都度ファイルシステムから作る。ルートディレクトリにアプリ用のファイルを作らないので、既存のフォルダをそのまま開ける。
2. **オフラインで動く**  
   アプリ本体の機能はすべてネットワークなしで動く。
3. **AI はシェル経由で使う**  
   AI 機能をアプリに組み込まず、PC にインストール済みの AI CLI をそのまま起動する。ツールの追加・更新はアプリの更新を待たずにできる。
4. **Git は PC の `git` を使う**  
   Git の処理をアプリに組み込まず、インストール済みの `git` コマンドを実行する。ユーザーの設定・認証・フックがそのまま効く。

## 検討中の事項

- **パソコン間の同期**: 初期の要件からは外し、実現方法を別途検討する。ルートディレクトリはただのフォルダなので、OneDrive などの同期フォルダや Git に置く運用とは、アプリ側の対応がなくても両立する。Git の場合は Git タブからコミット・プル・プッシュができる（[git.md](git.md)）。
